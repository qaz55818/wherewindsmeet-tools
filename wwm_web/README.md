# 燕雲十六聲 射覆題庫查詢工具

這是一個基於 Web 的射覆題庫查詢工具，專為《燕雲十六聲》玩家設計。

## 功能特點

- **快速搜尋**：即時篩選題目與答案。
- **響應式設計**：完美支援手機、平板與桌面電腦。
- **深色模式**：自動偵測系統設定，並提供手動切換開關。
- **離線支援**：包含 PWA Manifest（需搭配 Service Worker 與圖示以獲得完整體驗）。

## 安裝與使用

1.  確保目錄下有 `qa.json` 檔案（題庫數據）。
2.  直接用瀏覽器打開 `index.html` 即可使用。
3.  若要部署，請將所有檔案上傳至靜態網頁託管服務（如 Vercel, GitHub Pages, Netlify）。

## 檔案結構

- `index.html`: 主頁面結構。
- `style.css`: 樣式表（包含 Light/Dark 主題變數）。
- `script.js`: 邏輯控制（資料讀取、搜尋過濾、主題切換）。
- `qa.json`: 題庫資料來源。
- `manifest.json`: PWA 設定檔。

## 自定義

-若要更改圖標，請替換 `icon-192.png` 和 `icon-512.png`。
